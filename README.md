## 🗂️ Template Categories

| Category | Description |
|---|---|
| `homepage/` | Landing page variants — minimal, modern, corporate, e-commerce focused |
| `product-pages/` | Single product, category grids, and listing layouts |
| `checkout/` | One-page and multi-step checkout flows |

---

## ✨ Features

- Fully responsive (mobile, tablet, desktop)
- Semantic HTML5 with accessibility in mind (WCAG 2.1)
- WooCommerce-compatible structure
- Clean, modular CSS — easy to retheme
- CDN-based dependencies (Bootstrap, jQuery) — no build step needed
- Optimized for Core Web Vitals performance

---

## 🚀 Usage

Each template is a **standalone HTML file** — just open it in a browser:

```bash
git clone https://github.com/Kevork-Nexacrawl-dev/WordPress-E-Commerce-Design-Collection
cd WordPress-E-Commerce-Design-Collection
open homepage/e1-minimal.html
```

Templates are designed for direct conversion into WordPress themes or as visual references for client proposals.
